# 크리에이터 파일럿 자료 제공 약정 — 항목 초안

[가능성 검증](../feasibility-study.md) 파일럿에서 크리에이터에게 받는 자료와 약속을 정리한 **항목표**다. 약정서 문안이 아니다.

> 법률 검토 전 초안이다. 변호사가 이 항목으로 약정서를 쓰고, 그 전에는 모집하지 않는다.

## 1. 당사자와 자격
- 채널 운영자(개인 또는 사업자). 채널 소유를 확인한다: 스튜디오 화면 공유, 또는 채널 설명에 확인 문구를 잠깐 올리는 방식.
- 미성년자는 법정대리인과 함께 약정한다.
- 대본을 쓴 사람이 채널 운영자와 다르면, 그 작가의 서면 동의를 받은 대본만 받는다.

## 2. 받는 자료
| 자료 | 내용 | 받지 않는 것 |
|---|---|---|
| 대본 | 영상으로 만든 대본 원문 (.txt/.md) | 영상 파일, 출연자 얼굴·목소리 |
| 성과 | 스튜디오 고급 모드에서 내려받은 동영상별 표 데이터(조회수, 평균 조회율, 평균 시청 지속 시간, 좋아요, 댓글 수, 노출수, 클릭률) | 시청자 정보, 댓글 원문, 수익 |
| 대응표 | 영상 ID ↔ 대본 파일 | |

- 크리에이터가 자기 화면에서 직접 내려받아 준다. 우리는 크리에이터 계정에 접속하거나 API 권한을 받지 않는다.
- 제공자는 자료를 줄 권리가 있음을 보증한다(대본 저작권, 공동 작가 동의).

## 3. 이용 목적 (체크박스로 따로 받는다)
- [필수] **가능성 검증 분석**: 대본과 성과의 관계를 통계적으로 분석하고, 결과를 집계해 내부 판단에 쓴다.
- [필수] **블라인드 테스트**: 대본 원문을 비밀유지 서약을 받은 PD 평가자(5~8명)에게 채널·영상 정보 없이 보여 준다.
- [선택] **학습 이용**: 파일럿이 끝난 뒤에도 자료를 우리 흥행 판단 모델의 학습 데이터로 쓴다. 동의하지 않으면 파일럿이 끝날 때 지운다.

목적 밖으로 쓰지 않는다. 대본을 판매·공개하거나, 다른 크리에이터에게 보여 주거나, 대본 내용을 베껴 새 대본을 만들지 않는다.

## 4. 공개 범위
- 결과는 채널을 알아볼 수 없게 집계한 형태로만 밖에 말한다(예: "대본 1,000편, 채널 28곳에서 AUC 0.63").
- 채널 이름, 개별 영상 성과, 대본 문장은 공개하지 않는다. 사례로 쓰려면 따로 허락을 받는다.

## 5. 보관과 보안
- 암호화한 저장소에 두고, 분석 담당자만 연다. 제품 서비스 DB와 섞지 않는다.
- 보관 기간: 파일럿 종료 후 30일 안에 삭제한다. 학습 이용에 동의한 자료는 그 동의가 유지되는 동안 보관한다.

## 6. 철회
- 언제든 철회할 수 있다. 철회하면 7일 안에 그 채널의 자료를 지우고, 분석을 다시 돌린다.
- 이미 공개한 집계 결과(4장)는 되돌리지 않는다. 그 안에서 채널을 알아볼 수 없기 때문이다.
- 학습 이용 동의만 따로 철회할 수 있다. 이미 학습한 모델은 다음 학습 때부터 그 자료를 빼고 다시 만든다.

## 7. 크리에이터가 받는 것
- **채널 리포트**: 그 채널에서 잘된 대본과 아닌 대본의 차이(장면 구성, 대사 비율, 첫 장면 등).
- 전체 결과 요약.
- 보상: 금액·방식은 따로 정한다(정액, 또는 리포트로 대신).

## 8. 그 밖
- 약정 기간, 분쟁 해결, 손해배상 범위, 개인정보 처리 위탁 여부는 변호사가 정한다.
