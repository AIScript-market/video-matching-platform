# 흥행 판단 모델 — 1단계

목표는 "S급 PD는 아니어도 A급 PD 수준의 판단"을 영상 제작자에게 주는 것이다. 대본만으로 흥행을 맞히는 힘은 생각보다 약하다.
대본 기반 예측 연구(Eliashberg 등)도 오차를 줄이는 정도였고 표본이 작았다. 유튜브 단편의 성공 조건(첫 30초 이탈, 시청 지속 시간)도
지상파·영화 흥행과 다르다. 그래서 세 층으로 쌓는다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1. 커버리지 리포트 | AI가 PD 관점으로 대본을 검토 (훅·갈등·인물·전개·대사, 제작 난이도, 강점·고려할 점) | **이번에 추가** |
| 2. 비슷한 작품 찾기 | 대본 임베딩으로 구조·톤이 비슷한 성공작·실패작 제시. 라이선스 받은 코퍼스 필요 | 다음 |
| 3. 예측 모델 | 우리 채널에 올라간 작품의 성과로 학습 ("상위 20%일 확률 + 불확실성") | 성과 데이터 수백 편 이후 |

## 이번에 만든 것

### 커버리지 리포트 (`Script.aiSummary.coverage`)
- 워커가 AI 요약을 만들 때 함께 만든다(`apps/worker/src/summary.ts`의 `CoverageSchema`).
  API 키가 없으면 mock 요약기가 장면 머리·인물 이름·낱말로 대략 계산한다.
- `scores`(각 1~5): `hook` 첫 장면 훅, `conflict` 갈등, `characters` 인물, `pacing` 전개, `dialogue` 대사
- `productionDifficulty`(1~5, 높을수록 어렵다), `estimatedCast`, `estimatedLocations`
- `strengths`, `risks`(각 최대 3개), `comparableTitles`(최대 3개, 확실하지 않으면 비움)
- **점수는 작가 본인·비로그인·목록에는 보내지 않는다.** 작가가 점수에 맞춰 쓰기 시작하면 점수가 의미를 잃고 대본도 뻔해진다.
  작가에게는 강점·고려할 점 같은 의견만 보인다. 영상 제작자(로그인한 다른 사람)와 관리자는 상세 화면에서 점수까지 본다.
- 화면에는 "참고용 · 흥행 예측이 아닙니다"를 항상 함께 표시한다.

### 학습 동의 (`Script.trainingConsent`)
- 대본마다 작가가 고르는 **선택** 항목이다. 기본은 동의 안 함. 언제든 끌 수 있다(`trainingConsentAt` 기록).
- 동의한 대본도 **원문은 학습 데이터로 내보내지 않는다.** AI가 뽑은 특징(커버리지)과 작품 성과만 쓴다.
- 나중에 원문 임베딩(2단계)을 쓰려면 동의 문구를 바꾸고 다시 받아야 한다(문구에 "원문을 내보내지 않는다"고 약속했으므로).

### 작품 성과 (`WorkPerformanceSnapshot`)
- 공개한 작품의 조회수, 시청 시간, 평균 시청 지속 시간, 좋아요, 댓글, 구독 증가, 수익을 시점별로 쌓는다.
- 지금은 기획사·관리자가 유튜브 스튜디오 숫자를 옮겨 적는다(`source = MANUAL`). 채널을 직접 운영하게 되면
  유튜브 분석 API로 자동 수집한다(`source = YOUTUBE_API`). 분석 API는 채널 소유자만 읽을 수 있다.
- 조회: 기획사, 출연자·보호자, 관리자. 기록: 기획사, 관리자.

### 학습용 데이터 (`GET /admin/ml/training-set`, 관리자)
- 동의한 대본마다: 장르, 예상 등급, 커버리지, 요약 모델, 전문 길이, 그 대본으로 만든 공개 작품과 최근 성과(공개 후 경과 일수 포함).
- 대본 원문은 들어가지 않는다.

## 다음에 할 것
1. **블라인드 테스트 세트**: 결과를 이미 아는 대본으로 "모델 고르기 vs PD 패널 고르기 vs 장르 평균"을 비교할 준비
   (이 숫자가 영업·투자 자료가 된다).
2. **유튜브 분석 API 연동**: 채널 OAuth, 하루 한 번 성과 수집, 공개 후 7일·30일 시점 성과를 정답으로 고정.
3. **2단계 비슷한 작품 찾기**: 한국영상자료원·작가협회 등과 연구 목적 라이선스 협상. TDM 면책 조항이 아직 없으니 허락받은 코퍼스만 쓴다.
4. **탐색 할당**: 추천의 10~20%는 비정형 대본에 배정해 모델이 뻔한 대본만 고르지 않게 하고, 맹점을 줄이는 데이터를 모은다.
5. **평가 원칙**: 시간 순서로 나눈 검증(미래 데이터로 과거를 맞히지 않게), 확률 보정, 장르 평균 대비 개선을 기준으로 삼는다.
