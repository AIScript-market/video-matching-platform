# Video Matching Platform

대본 작가와 영상 제작자를 연결하고, 배우·성우의 얼굴과 목소리를 **동의와 라이선스에 근거해 합법적으로** 쓸 수 있게 하며, 참여자 전원의 정산까지 처리하는 플랫폼.

## 핵심 기능

- **대본**: 업로드, 버전 관리, AI 요약 (장르·수위 분류 포함)
- **매칭**: 작가 ↔ 제작자 연결, 프로젝트·계약·마일스톤 관리
- **탤런트 자산**: 배우·성우가 얼굴·음성을 등록하고 사용 범위와 단가를 직접 설정
- **AI 합성**: 유효한 라이선스가 있을 때만 음성·얼굴 합성 허용, 생성물에 AI 표시
- **정산**: 작가·제작자·배우·성우 수익 분배, 원천징수, 지급

## 협업 규칙 요약

1. `main`에 직접 push하지 않고, 짧은 기능 브랜치(1~3일)에서 PR을 올린다.
2. PR은 1명 이상 리뷰 후 squash merge 한다.
3. API를 바꿀 때는 OpenAPI 스펙 변경 PR을 먼저 올려 합의한다.
4. 이미 머지된 DB 마이그레이션은 수정하지 않는다.
5. 비밀 키는 저장소에 커밋하지 않는다. `.env.example`만 커밋한다.
6. 개발·스테이징 환경에 실제 배우의 얼굴·목소리 데이터를 넣지 않는다.
